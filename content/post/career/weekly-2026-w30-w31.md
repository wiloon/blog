这两周的周记合成一篇。

## enx：先把功能做完，上线再说

enx 是我自己的项目，一个查词加翻译的 Chrome 扩展。这两周它是主线。

前一周主要在部署链路上：调查词性能（SQLite 相关的调整、给 words 表加索引的 migration），构建时把 version 注入镜像，Go API、Java API 和 UI 三条镜像链路陆续跑通，部署到 homelab。

后一周是功能推进：

- 合入本地 ECDICT 词典，查词路径不再依赖外部接口
- 单词弹窗迁到 React + Shadow DOM，样式不会再被宿主页面污染
- 加了句子翻译的 Side Panel，翻译后端做成多 provider（MiniMax、Bedrock、Kimi），用 factory 加 handler 分派
- 修扩展的 session 超时问题，Cognito 那边改成手写刷新逻辑

周六在岛上想清楚一件事：微信登录先不做了。现在已经有 Google 登录，把 Stripe 接上就可以上线部署。把基本功能做完先上线，不需要等到完美。

## 一个朋友的文档校验工具

之前写过的、给一位朋友做的文档校验工具，这两周继续往前走。

前一周主要是仓库骨架落地：架构 ADR、几个模块的 Spec、测试，周末开始写 Web UI 的 SDD 和 lint 配置。后一周把它部署进了测试环境。

另外这个项目按正常的需求分析、报价流程走一遍。因为如果以后真的在线接单，报价是绕不开的问题，正好拿它测试一下。

## w_dashboard：一个玩具级的仓库看板

周末起了个新项目 w_dashboard，Linux 端用 Rust 加 Slint，macOS 端用 Swift 加 SwiftUI，两端各写了一版初版。

起因很实际：我有两台机器，一台 PC 一台笔记本，手上同时维护好几个 git 仓库，经常不确定哪个仓库本地有改动还没提交。这个 dashboard 就是出门之前扫一眼——哪些仓库没同步，顺手提交一下。工具本身是玩具级别的，顺便也是对这两个平台原生应用的一次尝试。

## blog：loop 和 graph engineering

blog 这两周写得比较杂：Agent 开发系列、Claude Code、Graph Engineering，后一周多了 loop engineering 和一篇讲 AI 时代软件项目怎么定价的。前一周还写了 Starship Flight 13 和 homelab 的拓扑。

## 广鹿岛

老婆年假没休完，周末全家坐船去了广鹿岛。

女儿四岁半，第二次来这里，从上船就开始兴奋，跑去甲板喂海鸥，午觉都没睡。

下午退潮，带她去海滩上捉螃蟹。天快黑的时候，我在沙滩上挖了个小坑，刚挖两下就有海水渗出来。我们把捉到的螃蟹和小鱼都放进小沙坑里，她蹲在旁边跟它们玩了一会儿。后来潮水涨上来淹没了小沙坑。

她说："螃蟹们都回大海去找妈妈了。"

2026 年 8 月 1 日，广鹿岛。
