临近国庆节，节奏有点乱。有四周没写周记了，W38 到 W41 合成一篇。这四周的主线还是 enx：给它取了个名字叫 Catglish，部署生产环境。最近在准备提交 Chrome Web Store，提交之前得再调整一轮 UI。

## Catglish

[W37](./weekly-2026-w37.md) 里纠结的名字，最后用了 Catglish。网站和 Chrome 扩展上的名字都改成了 Catglish，仓库名还是 enx，等上线之前再找时间改。

W38 主要在调细节。跟 AI 一起重新做了一遍配色，统一了各个组件的颜色 token。在颜色这件事上，AI 比我专业多了。周五 Claude Code 赠送的 100 美元额度第二天就要过期，那两天开着 Opus 改了很多东西，也第一次往生产环境部署了一个版本。

W39 在补生产环境的链路。部署流水线从 GHCR 加 SSH 换成了 ECR 加 SSM，机器调整成 t3a.small。扩展的内容脚本改成按需注入，不再在每个页面上都注入。周五集中做了一次依赖版本升级：Next 16、Vite 8、TypeScript 6。E2E 测试改成用真实的登录流程跑。

W40 是国庆：

- 网站上加了 Beta 标记和 GitHub 链接
- 加了定价页；现在的配额都是内测阶段的数字，跑一段时间再定上线时各个等级的额度
- 除了按月订阅，也可以一次性付款购买 AI 积分
- 本地词典查不到的词，可以调用 AI 生成释义
- 收藏页面，以及按站点设置「在这个网站上自动开启」

另外加了 Prometheus 监控指标，homelab 和生产环境的监控面板都接上了。

W41 打好了 0.1.0 Beta 的扩展包，画了个 logo：一个带猫耳朵的 C。

Chrome Web Store 提交的时候需要截图，所以现在在给网站和扩展弹窗做 UI 细节的小优化，调完这一轮就提交审核。

## 收款和公司

W38 研究了一圈收款方案：Stripe、Lemon Squeezy、香港个人账户，还有阿里的万里汇。公司注册在国内，没有海外实体，用香港个人账户收款可能会有问题。也在看海外注册一个 Wyoming LLC 的方案，不过先把内测版本放出去，LLC 后面再说。

公司 10 月做了第一次季度零申报。还是没有找代账公司，像 [W33](./weekly-2026-w33.md) 里说的那样，自己在 AI 的指导下做。公司现在没有收入，报的都是零。

遇到一个小问题：季末资产总额不能填 0，系统要求最少填 0.01 万元，也就是 100 块钱。但对公账户的余额实际上就是 0。报表强制要求，没有别的办法，就按 0.01 提交了。打算找时间按认缴的注册资本往对公账户里转一部分钱，余额不是 0，下次报税就不会遇到这个问题了。

## 帮初中同学写的小工具

一位初中同学在做保险销售，以前也在软件行业工作过，有一些开发经验，但离开这个行业很多年了。W38 的周末，我帮他写了一个分析销售线索、给线索打分的工具，只是一个能跑的命令行版本。

我给他介绍了一下现在的 AI 辅助编程。他下载了 ZCode，在 AI 的帮助下接着我的初版往下做，现在已经加上了 Web UI，做得还不错。

有了 AI 之后，不同行业的人，即使没有计算机背景，也能在 AI 的辅助下写一些工具了。

## meetsync：约个时间

有前同事想发起一次聚会，但大家的时间总是对不上。W39 的一个晚上，我写了一个多人约时间的小工具 meetsync：先写领域术语和几个 ADR，再一屏一屏地做原型，最后搭好了 Go 加 Next.js 的骨架。后面没有继续做，等以后有时间再说,先做主线任务。

上个月有空闲的时候，重新开始练钢琴。找了一本适合成年人练琴的书，放进了 calibre。calibre 是一个管理电子书的工具，之前在 homelab 上离线了很长时间，最近修好了，跑在家里的 K8s 集群里。

## 国庆：榆沟农场

国庆没去别的地方，带女儿去了两次榆沟农场。这是大连近郊的一个农场，不定期组织小朋友的活动，由老师带着。之前参加过摘梨、煮梨汤，中秋节做月饼，大多是结合他们山林的一些传统活动。

第一天的活动是捡柴烤披萨。上午老师带小朋友们上山捡柴火，回来自己做披萨，送进农场的窑炉里烤。下午捡树叶喂农场的小羊。

那天下午，大圣老师在搭一间小房子，要用黏土抹墙。小朋友们帮着和泥，往泥里加稻草，再抹到墙上。有的孩子直接上手，用手去捧泥巴；有的大概是怕把手弄脏，拿着铲子去铲。女儿是拿铲子的那一个。

我想起林子老师在活动群里提前发的一段「亲子参与原则」：

> 亲子家庭特别注意，活动中请成人带头做，少说多做。孩子是天生的观察者和模仿者。你弯腰拔花生的背影，洗手时关小水流，餐后整理清洗餐具，这些无声的行为，比任何说教都更有力量。你希望孩子成为什么样的人，你先去做那样的人。

我没有劝她，自己蹲下来，直接用手去捧泥巴，两只手很快都沾满了泥。女儿在旁边看了一会儿，把铲子放到一边，也伸手去抓泥巴了。

农场那个能烤披萨、烤面包的窑炉，回来我在网上查了一下怎么搭，要用耐火砖和耐火水泥。还学到一点：普通水泥被火反复烧会碎裂，所以要用耐火的材料。我跟女儿说，以后可以在奶奶家的院子里也搭一个。

另一天的活动是老师带小朋友们上山采野山楂，回来自己串糖葫芦。
