## 起因

调一个侧边栏卡片的下边距时遇到的问题。卡片是灰底圆角框，四周内边距都是 12px，框里上面是一句英文，下面是几张带彩色竖线（左边框）的小卡片。

- 内边距上下都是 12px，看上去下边比上边窄，像没收住。
- 给下面再加 12px，变成 24px，看上去又太宽，底部空出一块。
- 最后下边用 18px（12 + 6），看起来上下平衡。

在截图上量出来的数据：上边框到句子文字顶部视觉上约 18px，下边框到竖线底部 13px。代码里的数值一样，眼睛看到的却不一样。下面是解释这件事用到的几个概念。

## 几何间距 vs 光学间距

- **几何间距（geometric spacing）**：代码或设计稿里写的数值，盒子边缘到盒子边缘的距离，比如 `padding: 12px`。
- **光学间距（optical spacing）**：人眼实际感受到的距离，从一个元素的"可见墨迹"到另一个元素的可见墨迹。

两者经常不一致，原因是元素的盒子和它可见的部分不重合：

- **文字自带空白**。一行文字的行盒比字形高：行高（line-height）多出来的部分平分在上下（half-leading），字形上面还有一段空白（ascender 区域里小写字母用不到的部分）。所以文字上方 12px 的 padding，看上去接近 18px。
- **硬边没有空白**。边框、色块、竖线、图片这类元素画到盒子边缘为止，12px 就是 12px。
- **颜色深、对比度高的元素视觉重量更大**，会显得离边界更近。

延伸阅读关键词：half-leading、cap height、x-height、`text-box-trim`（CSS 新属性，用来裁掉文字上下的多余空白）。

## 光学补偿（optical compensation / optical adjustment）

既然几何上相等看起来不相等，就有意让几何数值不相等，换来视觉上相等。这是设计里很常见的做法：

- 字体设计里，圆形字母（O、C）会比方形字母（H）略高略大，否则看上去偏小（overshoot）。
- 播放按钮里的三角形要往右挪一点，才显得居中，因为三角形的视觉重心偏左。
- 图标按钮里，不同形状的图标要调成不同尺寸，才显得一样大。
- 上面的卡片：下边用 18px 去配上边"12px + 文字空白"的视觉 18px。

做法上一般是：先按几何规则排，再看实际渲染效果，最后把差值补在需要的地方。补偿只加在出问题的那个位置，不要为了它去改全局的间距。

## 格式塔接近性原则（Gestalt principle of proximity）

格式塔心理学（Gestalt psychology）研究人怎样把零散的视觉元素看成整体。接近性原则说：**距离近的元素被看成一组，距离远的被看成不同组**。

对 UI 间距的直接要求：

- **组内间距 < 组间间距**。一组里的元素靠得近，组和组之间隔得远，用户不需要边框也能分清分组。
- **容器内边距要明显大于容器内部元素之间的间距**（常被叫作 internal ≤ external 规则）。如果内边距和内部间距差不多，容器的边界就"读"不出来。

上面的卡片里，小卡片之间是 8px，最初到底边只有 12px，两者太接近，最后一张小卡片和底边之间的关系就和小卡片之间的关系差不多，于是看着像没收住。

格式塔原则还有几条，常一起出现：相似性（similarity）、闭合（closure）、连续性（continuity）、共同区域（common region，用边框或底色框起来的东西被看成一组）、图形与背景（figure-ground）。

## 视觉收尾（visual closure / containment）

"没收住"是一种直觉描述，指一个区块的结尾没有给眼睛明确的终止信号。常见原因：

- 最后一个元素离容器边缘太近，或者和内部间距一样，眼睛分不清是"到底了"还是"后面还有"。
- 最后一个元素是硬边（竖线、色块），把视线一直带到边框上。
- 上下内边距在视觉上不对称：上面松、下面紧，整体像被截断。

反过来，底部留得太多也不好：多出来的空白没有内容去解释它，看上去像缺了一块或者布局出错。合适的收尾一般是：底部视觉间距和顶部视觉间距相当，并且明显大于内部元素之间的间距。

## 间距体系（spacing scale）

和上面几条配合使用的工程做法：

- **4pt / 8pt 网格**：所有间距取 4 或 8 的倍数（4、8、12、16、24…），Tailwind 的 `p-1`、`p-2`、`p-3` 就是 4px、8px、12px。
- **间距分层**：同一层级用同一个值，层级越外，间距越大。比如字段内 4px、字段间 8px、卡片内边距 12px、卡片之间 16px。
- 光学补偿可以用网格里的半格（比如 6px）去微调，补偿值本身也尽量落在体系内。

## 小结

| 概念 | 一句话 |
| ---- | ------ |
| 几何间距 | 代码里写的距离，盒子边到盒子边 |
| 光学间距 | 眼睛看到的距离，可见内容到可见内容 |
| 光学补偿 | 故意让几何数值不等，换来视觉上相等 |
| 格式塔接近性 | 近的成组，远的分开；容器内边距要大于内部间距 |
| 视觉收尾 | 区块结尾要给出明确的终止信号，不紧也不空 |
| 间距体系 | 用固定的间距档位分层，补偿也尽量用档位里的值 |
