我之前订阅的是 Cursor Pro，每月 20 美元。2026 年 10 月 12 日，X 推出了统一订阅（The X Subscription），把 X Premium、Grok（SuperGrok）和 Cursor 合到了一个订阅里。我把 Cursor Pro 转成了统一订阅的 Premium 档。

同样是 Premium 年付，从 Cursor 那边转过去，首年约 16 美元/月；直接在 X 或 grok.com 上订，是 25 美元/月。这是给 Cursor 老用户的首年折扣，从 X 那边看不到。

## 为什么要换

- 我想要 X 的蓝 V（Premium checkmark），用来推广自己的产品 ENX。
- 写代码我主要用 Claude 的订阅，Cursor 用得不多，所以统一订阅里 Cursor 不包含 Claude 用量这一点，对我影响不大。
- 原来 Cursor Pro 一年 240 美元，统一订阅 Premium 年付原价 300 美元，多 60 美元，多出来的是 SuperGrok 和 X Premium+ 的权益。

## 统一订阅的档位

X 页面（x.com/i/premium_sign_up）上的年付价格：

| 档位 | 年付 | 折合每月 | 用量 |
| ---- | ---- | -------- | ---- |
| Plus | $80 | $7 | 基准 |
| Premium | $300 | $25 | Plus 的 4 倍 |
| Super | $1,000 | $84 | Plus 的 15 倍 |
| Ultra | $2,000 | $167 | Plus 的 50 倍 |

Plus 档也带蓝 V，但没有 Grok Bot，在 Cursor 里只能用 Grok 模型。Premium 档包含 Cursor、Grok Bot、Grok（Chat、Voice、Imagine、Build、API），X 这边有去广告、蓝 V、创作者工具和高级数据分析。

## 从 Cursor 那边看到的价格

用 Cursor 账号打开 cursor.com/unify，到选择档位那一步（Step 3 of 4），Premium 年付显示的是：

- $16/month
- 36% off for 1 year, then $300/year
- 2x usage compared to your current plan

页面左侧显示当前是 Cursor Pro（$20/mo），下面有一行 Prorated refund will be applied，意思是买了新订阅之后，原来的 Cursor Pro 会被取消，没用完的部分按比例退款。

算一下：300 × 0.64 = 192 美元，折合每月 16 美元。第一年比在 X 上订便宜 108 美元，第二年起恢复 300 美元/年。Super 和 Ultra 在 Cursor 页面上没有这个折扣，价格和 X 上一样。

## 2x 和 4x 不矛盾

两个页面对 Premium 用量的说法不一样，一开始我以为是两个不同的档位：

- Cursor 页面：2x usage compared to your current plan，跟我现在的 Cursor Pro 比。
- X 页面：4x usage compared to Plus，跟 Plus 档比。

两个说法放在一起，可以推出 Plus 的用量大约是 Cursor Pro 的一半。说的是同一个 Premium。

## 操作步骤

1. 打开 cursor.com/unify。
2. 依次登录要合并的 Cursor、Grok、X 账号，邮箱可以不一样。X 账号要选需要蓝 V 的那个。
3. 选 Premium、年付，确认价格是首年折扣价、页面有 Prorated refund 的提示。
4. 付款。直接向 Cursor 付费的 Cursor Pro 会在结账时取消，按比例退款到原来的付款方式，几天内到账。新订阅当天生效。
5. 回到 cursor.com 的 Billing & Invoices，确认旧的 Cursor Pro 已经取消。

## 需要注意的地方

- 入口要从 Cursor 发起。从 X 或 grok.com 订阅不会合并 Cursor 账号，也不会取消原来的 Cursor Pro，可能会两边都扣费，也拿不到首年折扣。
- 账号合并是永久的，客服也不能拆开。之后就算取消统一订阅，也回不到原来 20 美元的 Cursor Pro。
- 如果 Cursor 是在 iPhone 上通过 App Store 订阅的，切换不会自动取消它，要自己去 iPhone 的「设置 → 你的名字 → 订阅」里取消。
- 统一订阅的所有档位都不包含 Cursor 里的第三方模型（Claude、GPT）。Premium 及以上可以用，但从第一个请求开始按 API 价格从预付余额里扣。原来的 Cursor Pro 每月约 20 美元的用量是可以用在 Claude 上的。如果在 Cursor 里主要用 Claude，换之前要算一下。
